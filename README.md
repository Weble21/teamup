# TeamUp 사용 설명서

TeamUp은 모임에서 **오늘 참석할 사람을 고르고, 선수들의 실력을 고려해 팀을 나누고, 확정한 명단을 기록하는 서비스**입니다.

[TeamUp 열기](https://teamup-two-ecru.vercel.app/) · [로그인 없이 팀 편성 연습하기](https://teamup-two-ecru.vercel.app/?guest=1)

## 휴대폰 홈 화면에 설치하기

- **Android** — 사이트의 **TEAM UP을 홈 화면에 → 설치하기**를 누르세요. 버튼이 **설치 방법**으로 표시되면 Chrome 메뉴의 **앱 설치** 또는 **홈 화면에 추가**를 선택하세요.
- **iPhone** — Safari에서 사이트를 열고 **공유 → 홈 화면에 추가 → 추가**를 선택하세요. **웹 앱으로 열기**가 표시되면 켜 주세요.
- 설치 후 홈 화면의 **TEAM UP** 아이콘으로 실행하세요. 로그인 상태를 확인하고 **운동 일정 투표 → 가입한 모임의 새 일정 알림 받기**에서 알림을 허용하세요.

## 모임장이 처음 팀을 나눌 때

1. **모임 만들기** — 카카오 또는 네이버로 로그인하세요. **내 모임 → 새 모임 만들기**에서 모임 이름과 종목을 정하세요.
2. **선수 등록하기** — 만든 모임을 열고 **회원 관리 → 회원 추가**에서 이름, 포지션, 능력치를 입력하세요. 모임원이 직접 가입하려면 모임 화면에서 초대 링크를 발급해 공유하세요.
3. **팀 나누기** — 모임 화면의 **빠른 팀 편성**에서 팀 수와 오늘 참석할 선수를 선택하고 **팀 나누기**를 누르세요. 예를 들어 6명을 선택하고 2팀으로 나누면 3명씩 편성됩니다.
4. **명단 저장하기** — 결과에서 서로 다른 팀의 선수 두 명을 차례로 누르면 자리를 바꿀 수 있어요. **결과 확정하기**를 누르면 **이전 경기 기록**에서 명단을 다시 볼 수 있습니다.

## 초대받은 모임원이 할 일

- **가입하기** — 초대 링크를 열고 로그인하세요. 선수 명단에 본인이 있으면 이름을 고르고 **선택하고 가입하기**를 누르세요. 처음 등록한다면 **명단에 없어요 · 내 정보 등록**을 선택하세요.
- **참석 알리기** — 모임의 **운동 일정 투표**에서 일정을 열고 **참석**, **불참석**, **보류** 중 하나를 고르세요. 투표가 마감되면 모임장이 참석 명단을 불러와 팀을 나눌 수 있습니다.
- **새 일정 알림 받기** — 로그인 후 **운동 일정 투표 → 가입한 모임의 새 일정 알림 받기**를 누르고 기기에서 허용하세요. 알림을 누르면 해당 투표가 열립니다. iPhone에서는 TeamUp을 홈 화면에 추가한 뒤 그 아이콘으로 열어 주세요.

게스트로 연습한 모임과 경기 기록은 **현재 브라우저에만 저장**되며, 나중에 로그인해도 계정으로 옮겨지지 않습니다.
