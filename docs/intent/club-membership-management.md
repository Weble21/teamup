# 모임 탈퇴·삭제 및 모임장 권한 관리: 작업 의도

## 목표 (Why)

회원이 더 이상 참여하지 않는 모임에서 탈퇴하고, 모임장은 운영 권한을 위임하거나 함께 운영할 모임장을 추가할 수 있게 한다. 모임을 영구 삭제할 때는 삭제되는 데이터와 영향을 명확하게 안내하고 사용자가 직접 확인하도록 한다.

## 확정된 요구사항

### 탈퇴

- 일반 회원은 자신이 가입한 모임에서 탈퇴할 수 있다.
- 탈퇴 즉시 해당 모임의 접근 권한과 새 활동 참여 권한을 종료한다.
- 탈퇴해도 기존 경기 기록·투표·댓글 등 과거 기록은 유지한다.
- 탈퇴 이력을 이유로 재가입을 제한하지 않는다. 초대 링크를 통해 다시 가입할 수 있다.
- 마지막 모임장은 다른 회원에게 모임장 권한을 넘긴 뒤 탈퇴해야 한다. 다른 모임장이 있다면 탈퇴할 수 있다.

### 모임장 위임 및 추가

- 모임장은 같은 모임의 회원에게 모임장 권한을 위임할 수 있다.
- 기존 모임장 권한을 유지하면서 추가 모임장을 지정할 수도 있다.
- 모든 모임장은 동일한 권한을 가진다. 기존 모임장과 추가 모임장 사이에 권한 차이를 두지 않는다.
- 모든 모임장은 다른 모임장의 지정·해제 및 모임 삭제를 수행할 수 있다.
- 권한 해제나 탈퇴로 모임장이 한 명도 남지 않는 상태를 허용하지 않는다.

### 모임 영구 삭제

- 모임장만 모임을 삭제할 수 있다.
- 모임 삭제 시 모임과 관련된 선수 명단·운동 일정·투표·댓글·경기 기록을 모두 영구 삭제한다.
- 삭제된 모임에는 모든 회원이 접근할 수 없으며, 삭제된 데이터는 복구할 수 없다.
- 삭제 전 확인 모달에 제목, 영향 안내, 확인 입력란과 삭제 실행 버튼을 표시한다.
- 입력값이 `삭제`와 정확히 일치할 때만 삭제 실행 버튼을 활성화한다.
- 입력만으로 삭제하지 않고, 활성화된 삭제 실행 버튼을 눌렀을 때 삭제한다.
- 입력과 확인이 필요한 모달이므로 자동으로 닫지 않는다.

확인 모달 문구:

> **정말 삭제하시겠습니까?**
>
> 모임을 삭제하면 모든 회원이 이 모임에 접근할 수 없으며, 선수 명단·운동 일정·투표·댓글·경기 기록이 영구 삭제됩니다. 삭제된 데이터는 복구할 수 없습니다.
>

## 완료 기준

- 탈퇴 이후 해당 모임의 권한이 종료되고, 기존 기록은 조회 가능한 상태로 유지되며 재가입할 수 있다.
- 모임장 위임·추가·해제가 저장되고, 기존 모임장 전용 기능이 모든 모임장에게 동일하게 적용된다.
- 마지막 모임장의 탈퇴·권한 해제를 서버에서 막는다.
- 확인 입력과 삭제 실행을 거쳐 모임 및 관련 데이터가 모두 삭제된다.
- 일반 회원의 권한 변경·삭제 요청, 다른 모임을 대상으로 한 요청을 서버에서 거부한다.

## 이번 작업의 범위 밖 (Out of scope)

- 회원 강퇴 및 재가입 차단 기능.
- 삭제한 모임이나 데이터의 복구 기능.
- 모임장 사이의 상하 관계나 세분화된 권한 등급.

## 구현 시 확인 사항

- 기존 단일 모임장 모델과 모임장 권한 검사 위치를 확인하고, 현재 모임장을 보존하면서 여러 모임장을 지원한다.
- Controller·Service·Repository의 책임을 분리하고 화면과 서버의 권한 판단을 일치시킨다.
- 탈퇴와 선수 비활성화를 구분하고, 보존되는 기록의 참조 및 재가입 시 계정 연결을 검토한다.
- 동시 탈퇴·권한 해제 시에도 마지막 모임장이 사라지지 않도록 트랜잭션과 동시성 제어를 검토한다.
- 모임 삭제 시 외래 키와 연관 데이터 삭제 순서, 트랜잭션을 검토하고 다른 모임과 사용자 계정에 영향을 주지 않도록 한다.
- 작업 결과 알림에는 공통 Toast 규칙을 적용한다.
- 권한, 기록 보존, 재가입, 전체 삭제 및 기존 기능 회귀를 검증한다.
