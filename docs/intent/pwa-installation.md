# TEAM UP 홈 화면 설치

## 목표

휴대폰 사용자가 웹사이트를 홈 화면에 설치하고 TEAM UP 아이콘으로 앱처럼 실행할 수 있게 한다. 모임원들이 서비스를 다시 찾아오기 쉽게 하고, 설치한 환경에서도 기존 로그인과 일정 알림을 사용할 수 있도록 한다.

## 확정된 방식

- 사용자가 선택한 방식은 웹사이트를 홈 화면에 설치하는 PWA다.
- 기존 Vercel 프론트엔드와 Fly.io 백엔드 구성을 사용한다.
- 주 대상은 Android와 iPhone 사용자다.

## 완료 기준

- TEAM UP 이름과 아이콘으로 설치할 수 있도록 manifest와 플랫폼별 아이콘을 구성한다.
- 설치 후 아이콘으로 실행하면 휴대폰 화면에 맞는 독립 실행 화면이 열린다.
- 지원하는 브라우저에서는 사용자 동작으로 설치를 요청할 수 있게 한다.
- iPhone 등 직접 설치 요청을 지원하지 않는 환경에서는 해당 환경의 홈 화면 추가 방법을 안내한다.
- 설치된 환경에서는 설치 안내를 숨긴다.
- 로그인, 참석 투표 상세 링크, 기존 푸시 알림과의 동작을 점검하고 실제 기기에서 확인할 항목을 남긴다.

## 이번 작업의 범위 밖

- Google Play와 App Store 등록 및 네이티브 앱 제작.
- 오프라인 데이터 조회 및 오프라인 쓰기 기능.
- 기존 참석 투표와 푸시 알림의 기능 확대.

## 현재 확인한 설정

- frontend/app/manifest.js에 standalone manifest가 있다.
- frontend/app/layout.js에 manifest 연결과 appleWebApp 메타데이터가 있다.
- frontend/public/vote-push.js가 기존 푸시 알림을 처리한다.
- 구현 시 기존 서비스 워커와 설치 기능의 연동을 확인한다.

## 구현 및 검증

- 로그인 화면, 내 모임, 내 계정에 설치 UI를 표시한다. 설치 이벤트를 제공하는 브라우저는 설치 창을 열고, 그 외 환경에는 브라우저 메뉴를 이용하는 안내를 표시한다.
- standalone 실행과 iOS 홈 화면 실행을 감지해 설치 UI를 숨긴다.
- 기존 로고로 192px, 512px 아이콘과 180px Apple 아이콘을 구성했다.
- 기존 vote-push.js를 같은 루트 scope에 등록하며, 서비스 워커 응답에 캐시 재검증 헤더를 설정했다.
- 프론트엔드 lint, production build, 기존 테스트 15개가 통과했다.
- 로컬 production HTTP 응답에서 manifest, Apple 메타데이터, 아이콘 실제 크기, 서비스 워커와 캐시 헤더를 확인했다.
- 브라우저 자동화에 사용할 브라우저가 없어 화면 및 실제 설치 검증은 수행하지 못했다.

## 배포 후 실제 기기 확인

- Android Chrome에서 설치 버튼 또는 브라우저 메뉴로 설치하고 아이콘과 독립 실행 화면을 확인한다.
- iPhone Safari에서 공유 메뉴로 홈 화면에 추가하고 아이콘으로 실행한다. 설치 안내가 숨겨지는지 확인한다.
- 설치된 환경에서 카카오·네이버 로그인과 로그인 후 화면 복원을 확인한다.
- 설치한 앱에서 알림을 허용하고 새 투표 등록 알림이 도착하는지, 눌렀을 때 로그인 여부에 따라 해당 투표 상세까지 열리는지 확인한다.
- 일반 브라우저와 홈 화면 앱의 로그인·알림 권한은 각각 확인한다.
