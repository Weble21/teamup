# 운동 일정 참석 투표: 작업 의도

## 목표

모임장이 모임 안에서 독립적인 투표를 만들어 운동 일정을 등록하고, 모임원이 참석 여부를 선택하도록 한다. 기존 운동 일정 기능은 투표로 대체한다.

## 확정된 요구사항

- 모임장만 투표를 생성한다.
- 장소와 운동 날짜를 입력받아 제목을 기본 생성한다. 예: `26.11.24.(화) 장충체육관 운동`. 사용자는 제목을 직접 수정할 수 있다.
- 투표 항목은 라디오 버튼으로 선택하는 참석, 불참석, 보류 세 가지다.
- 모임원은 마감 전까지 선택을 변경할 수 있으며, 마감 후에는 변경할 수 없다.
- 생성자가 투표 마감 날짜와 시간을 직접 지정한다. 생성 시 마감 시각은 현재 시각으로부터 최소 4시간 뒤여야 한다.
- 모임원 모두가 항목별 인원과 이름을 확인할 수 있다.
- 마감 1시간 전 보류자와 미투표자에게 투표 확정을 요청하는 휴대폰 브라우저 푸시 알림을 보낸다. 사용자 알림 권한이 필요하다.
- 기존 운동 일정 데이터는 삭제하지 않고 보관한다.

## 이번 작업의 범위 밖

- 보관된 기존 운동 일정의 조회 화면. 추후 작업한다.
- 투표 결과와 팀 나누기의 참석자 선택 연동. 추후 작업한다.
- 웹을 휴대폰 홈 화면에 설치하는 기능. 추후 작업한다.

## 구현 전 확인 사항

- 현재 일정 관련 코드와 저장 구조를 확인해 기존 데이터를 보존하면서 기능을 대체하는 방법을 결정한다.
- 휴대폰 브라우저 및 운영체제별 웹 푸시 지원과 필요한 조건을 확인한다.
