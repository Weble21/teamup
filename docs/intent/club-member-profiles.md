# 모임별 내 프로필: 작업 의도

## 목표

종목별 공통 프로필을 없애고, 사용자가 가입한 모임마다 독립적인 선수 정보를 관리한다. MY 화면에서 모임으로 바로 이동하거나 해당 모임의 내 정보를 바로 수정할 수 있게 한다.

## 확정된 요구사항

- MY 화면의 종목별 내 프로필을 없앤다.
- 기존 종목별 공통 프로필 데이터는 삭제한다. 기존 모임별 선수 정보는 유지한다.
- MY 화면에서 가입한 모임 정보를 표시한다. 모임 정보를 클릭하면 해당 모임으로 이동한다.
- 각 모임 정보 아래에 정보 수정하기 버튼을 둔다. 버튼을 누르면 해당 모임의 내 프로필 수정창을 바로 연다.
- 같은 모임에 가입한 모든 사람은 선수의 이름, 포지션, 능력치, 나이, 추가 사항 등 모든 정보를 조회할 수 있다.
- 일반 모임원은 본인의 선수 정보만 수정할 수 있다. 모임장은 해당 모임의 모든 선수 정보를 수정할 수 있다. 서버에서도 권한을 검증한다.
- 모임 초대 링크를 열면 로그인 여부를 확인한다. 로그인하지 않았다면 로그인 후 초대 절차를 이어간다.
- 로그인한 가입자는 기존 선수 명단에서 본인이 있는지 먼저 확인한다. 본인이 있으면 선택해 계정과 연결하고, 없으면 새 모임별 프로필을 등록한다.

## 이번 작업의 범위 밖

- 모임 프로필 및 초대 가입과 무관한 기능의 대규모 개편.

## 구현 시 확인 사항

- 현재 초대 가입, 계정과 선수 정보의 연결, 모임별 프로필 조회·수정 흐름을 확인하고 기존 모임 선수 데이터와 경기 기록을 보존한다.
- 종목별 공통 프로필 데이터 삭제 범위와 DB 마이그레이션, 기존 API와 가입 과정에서의 사용처를 함께 확인한다.
- 선수 선택 시 이미 다른 계정과 연결된 정보를 잘못 연결하거나 중복 연결하지 않도록 서버에서 검증한다.
- 조회 및 수정 권한, 초대 가입의 기존 선수 선택과 신규 등록, 로그인 후 초대 절차 복귀를 검증한다.
