# TEAM / UP 프론트엔드

Notion 기획을 바탕으로 만든 Next.js 반응형 웹 미리보기입니다.

## 실행

```powershell
cd C:\Users\SSAFY\Desktop\teamup\frontend
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. Windows에서 `npm` 스크립트 실행이 차단된 경우 `npm.cmd`를 사용할 수 있습니다.

## 현재 범위

- 모임 생성, 회원 추가·수정·비활성화, 참석자 선택, 임시 팀 편성·교환 및 경기 기록 조회
- 게스트 데이터는 서버에 전송하지 않고 해당 브라우저의 localStorage에 보관합니다. 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 접근할 수 없습니다.
- 능력치를 모르는 회원의 임시 계산은 해당 회원을 제외한 활성 회원 평균을 기준으로 하고, 평균에서 5를 뺀 뒤 반올림하여 최소 1점으로 보정합니다. 기준 회원이 없으면 직접 입력합니다. 정책은 확정 전입니다.
- 편성은 단순한 능력치 기반 미리보기이며 서버 검증, 필수 제약, 포지션 균형 및 최적해를 제공하지 않습니다.
- 로그인, API, 데이터 영구 저장, 자연어 조건, 계정 삭제는 구현하지 않았습니다.
- 웹 매니페스트가 있지만 홈 화면 설치와 기기별 PWA 동작은 검증하지 않았으며 오프라인 사용을 제공하지 않습니다.

## 검증

```powershell
npm.cmd run lint
npm.cmd run build
```
