# TEAM / UP 프론트엔드

Notion 기획을 바탕으로 만든 Next.js 반응형 웹앱입니다. 게스트 모드와 소셜 로그인 기반 서버 모드를 제공합니다.

## 실행

```powershell
cd C:\Users\SSAFY\Desktop\teamup\frontend
npm.cmd install
npm.cmd run dev
```

터미널에 표시된 로컬 주소를 브라우저에서 엽니다. Windows에서 `npm` 스크립트 실행이 차단된 경우 `npm.cmd`를 사용할 수 있습니다.

## 현재 범위

- 모임 생성, 회원 추가·수정·비활성화, 참석자 선택, 임시 팀 편성·교환 및 경기 기록 조회
- 게스트 데이터는 서버에 전송하지 않고 해당 브라우저의 localStorage에 보관합니다. 브라우저 데이터를 삭제하거나 다른 기기를 사용하면 접근할 수 없습니다.
- 능력치를 모르는 회원의 임시 계산은 해당 회원을 제외한 활성 회원 평균을 기준으로 하고, 평균에서 5를 뺀 뒤 반올림하여 최소 1점으로 보정합니다. 기준 회원이 없으면 직접 입력합니다. 정책은 확정 전입니다.
- 게스트 편성은 브라우저 내 미리보기입니다. 로그인 모드는 서버에서 소유권·참석자·팀 인원을 검증합니다. 두 모드 모두 포지션 균형·추가 필수 제약·최적해를 보장하지 않습니다.
- 로그인 모드에서는 모임·회원 관리, 편성·서버 교환 검증, 경기 확정·기록 조회를 Spring API로 처리합니다. 게스트 데이터는 자동 업로드하거나 병합하지 않습니다.
- 로그인 시 세션 쿠키를 사용하고, 변경 요청마다 CSRF 토큰을 받아 전송합니다. 인증 토큰을 localStorage에 저장하지 않습니다.
- 자연어 조건, 같은 팀/다른 팀 제약, 포지션 균형, 계정 삭제는 구현하지 않았습니다.
- 웹 매니페스트가 있지만 홈 화면 설치와 기기별 PWA 동작은 검증하지 않았으며 오프라인 사용을 제공하지 않습니다.

## 서버 연결

백엔드는 Java 25·MySQL 환경에서 `oauth` 프로필로 실행합니다. Next.js는 `/api`, `/oauth2`, `/login/oauth2`를 `BACKEND_URL`로 프록시하며 기본값은 `http://127.0.0.1:8080`입니다. 브라우저에서는 `http://localhost:3000`을 사용합니다.

백엔드 `.env`에 실제 제공자 인증 정보와 `APP_BASE_URL=http://localhost:3000`을 설정합니다. 제공자 콘솔 콜백도 `http://localhost:3000/login/oauth2/code/{google|kakao|naver}`로 맞춥니다. `APP_BASE_URL`을 바꾸면 콘솔 설정도 함께 변경해야 합니다.

로그인 후 모임·회원 관리 → 참석자 선택 → 편성 → 다른 팀 선수 2명 교환 → 결과 확정 → 경기 기록 조회 순으로 사용합니다. 기록 목록은 페이지 단위로 불러오며 ‘기록 더 보기’로 이어서 조회합니다. 같은 서버 입력의 재편성은 같은 후보를 반환합니다.

API 계약과 검증 범위는 [API 문서](../docs/API.md)를 참고하세요. 실제 제공자 로그인과 휴대폰 동작은 별도의 수동 검증이 필요합니다.
